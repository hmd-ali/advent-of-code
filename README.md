# Advent of Code

## Running Solutions

Run a specific day and part:
```bash
pnpm start <year> <day> <part>
```

Example:
```bash
pnpm start 2025 1 2
```

Run with example input:
```bash
pnpm start:example <year> <day> <part>
```

Example:
```bash
pnpm start:example 2025 1 1
```

## Structure

- Solutions: `src/<year>/<day>/part-one.ts` and `part-two.ts`
- Inputs: `inputs/<year>/<day>.txt`
- Example inputs: `inputs/<year>/<day>-example.txt`
